# Snowbound Dispatch

`snowbound_dispatch.wav` is an original instrumental composition and synthesized
recording made for JingleShells. It uses a celesta-like lead, soft sustained chords,
plucked accompaniment, bass, and synthesized sleigh bells in a 32-bar Christmas
waltz at 112 BPM. Duration: approximately 51.43 seconds, stereo, seamless loop.

Both the note sequence and the instrument synthesis are in
`art/audio/build_menu.cjs`. Rebuild from the repository root with:

```sh
node art/audio/build_menu.cjs
```
